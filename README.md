# 🆔 CIE & Driver's License Photo Maker (Fototessera Generator)

A 100% free, client-side web application to create perfectly compliant ID and driver's license photos (CIE & Patente) according to ICAO standards. Completely private—all processing happens directly in your browser.

Un'applicazione web 100% gratuita e client-side per creare fototessere a norma per CIE e Patente di guida (standard ICAO). Totale privacy: l'elaborazione avviene interamente nel browser.

---

## ✨ Features / Caratteristiche
- **ICAO Compliant**: Generates standard 35x45 mm photos / Genera foto standard 35x45 mm.
- **Custom DPI & Dimensions**: Default set to 500 DPI with built-in metadata / Dimensioni e DPI personalizzabili (Default: 500 DPI con metadati integrati).
- **Smart Compression**: Keeps single files under 500 KB for official portals / Mantiene il file singolo sotto i 500 KB per i portali PA.
- **Print Sheet (10x15 cm)**: Automatically creates a 4-photo grid with cutting borders for cheap printing / Crea automaticamente una griglia 4 foto in formato cartolina 10x15 cm.
- **100% Privacy**: No server uploads; your photos never leave your device / Nessun upload su server; le foto restano sul tuo dispositivo.

---

## 🚀 Usage / Utilizzo
1. Open the web app (hosted via GitHub Pages) / Apri l'applicazione web.
2. Drag and drop or select your photo / Trascina o seleziona la tua foto.
3. Position and zoom your face inside the oval guide / Posiziona e zooma il viso dentro la guida ovale.
4. Download your single digital photo or the 10x15 print sheet / Scarica la foto singola o il foglio di stampa.
